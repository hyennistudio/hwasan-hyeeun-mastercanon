# 연표

## 작성 규칙
- 작품 내부 연도 기준으로 기록합니다. 기준 연도가 확정되지 않은 경우 `미정`으로 둡니다.
- 모든 행은 [sources/index.yaml](../sources/index.yaml)의 출처 ID를 가져야 합니다.
- 상태: `draft` / `confirmed` / `disputed` / `superseded` ([RULES.md](RULES.md) 참고).
- 충돌하는 연도는 [review/unresolved.md](../review/unresolved.md)에 기록합니다.
